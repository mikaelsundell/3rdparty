3rdparty packages:

Shared Mac and Windows build driver
---------------------------------
* build.sh and build.bat start build.py, which configures and builds CMake
  directly. CMake projects use Ninja on both platforms; Mac retains Autotools/
  Make builds, its normal prefixes, deployment target and SDK, Qt module
  options, and multi-config tool installation.
* Check required Python modules for the selected Mac build using the same
  interpreter passed to CMake. Full builds retain base, Qt, libraries/extras
  ordering and stop when any stage fails.
* Select Mac tool and package search paths per configuration. Remove inherited
  project Debug/Release bin entries, append the selected prefix after system
  tools, and set CMAKE_PREFIX_PATH and PKG_CONFIG_PATH for that prefix.
* Build Boost's Mac dylibs with -headerpad_max_install_names so post-install
  normalization can replace short library IDs with the install-prefix paths.
  Include the additional Boost 1.87 dylibs in output tracking and normalization.
* Use OPENEXR_BUILD_PYTHON for OpenEXR 3.4.6 on Mac as well as Windows. Pass
  the selected prefix and interpreter, declare the pybind prerequisite, and
  track the upstream python/OpenEXR module installation. The Mac patch
  src/openexr/python-debug-postfix.patch clears the Python target's Debug suffix
  so it imports as OpenEXR; C++ library Debug suffixes are preserved. Track the
  new exrmanifest, exrmetrics, and exrstdattr tools for path normalization.
* Share OCIO's disabled CPU/GPU test settings and default OpenEXR app backend
  across platforms. OCIO tests must not discover OIIO during bootstrap, since
  OIIO itself requires OCIO. Keep the OCIO applications enabled.
  Forward the selected Mac deployment target explicitly because OCIO sets its
  own 10.15 default before project(), overriding the environment's default.
  Track and normalize all OCIO 2.5 command-line apps, including ocioarchive,
  ociocpuinfo, and ociomergeconfigs.
* pkg-config-0.28.tar.gz remains unchanged. The in-tree
  src/pkg-config/reinstall-host-tool.patch replaces its host-tool hard link
  during installation, allowing a normal repeat install into the same prefix.
* OIIO's Mac recipe explicitly uses the project JPEG dependency, matching the
  Windows option and avoiding optional libjpeg-turbo package discovery.
* CMake recipes configure with the selected generator and use cmake --build
  and cmake --install. Preserve the Mac CPU/load limits with num_cpus; the
  driver runs one Mac package command at a time. OIIO keeps its upstream
  wrapper and settings with USE_NINJA=1 and a bounded compiler job count.
  Qt and PySide retain their existing Ninja configurations. Mac bootstraps
  the existing Ninja recipe with Make in build/tools when no external Ninja
  is available. Windows still requires Ninja on PATH. Old Makefile caches
  require a fresh build directory when switching generators.
* nanogui-master-240216.tar.gz remains unchanged. The in-tree
  src/nanogui/macos-deployment-target.patch makes its hard-coded 10.14 target a
  default, allowing the recipe to forward the selected Mac deployment target.

Windows base dependencies
---------------------------------
* The MSVC recipes use the existing S3 source archives.
* Windows port patches live in the corresponding src/<package>/msvc directory.
* giflib-5.1.4.tar.gz extracts as giflib-5.1.4. windows-exports.patch adds
  Windows DLL import/export declarations for the font array.
* harfbuzz-4.3.0.tar.gz extracts as harfbuzz-4.3.0. install-subset-runtime.patch
  installs the subset DLL even when building without the CLI tools.
* libwebp-1.2.2.tar.gz extracts as libwebp-1.2.2. msvc-tool-data-imports.patch
  selects the upstream DLL mode for the command-line tools and uses a DSP
  function to avoid linking a data symbol from the extras tool.
* pcre2-10.32.tar.gz extracts as pcre2-10.32. modern-cmake-tests.patch replaces
  the removed CMake LOCATION policy with a configuration-specific test script.
* tiff-4.0.3.tar.gz extracts as tiff-4.0.3. modern-msvc-stdio.patch retains the
  snprintf compatibility macro for older toolchains.
  export-exif-directory-api.patch exports the two EXIF directory functions
  used by OpenImageIO.
* zlib-ng-2.3.3.tar.gz extracts as zlib-ng-2.3.3.
  windows-pkg-config-library.patch records the MSVC library name in zlib.pc.
* The MSVC recipes in src/bzip2/msvc, src/giflib/msvc, src/jpeg/msvc, and
  src/tiff/msvc supply build entry points for archives without upstream CMake
  projects. jpegsrc.v9f.tar.gz extracts as jpeg-9f.

  Its python-debug-postfix.patch gives the Debug module a stable _d.pyd name

  Designer bindings on the same full Python API as the rest of PySide.
  detect-debug-python.patch detects Windows Debug CPython when sysconfig
  does not expose Py_DEBUG. load-sdk-dlls.patch lets Shiboken and PySide
  load the runtime DLLs from their own install prefix.
  python39-callable-annotations.patch normalizes Callable annotations from
  Python 3.9.0 so QtCore type stubs can be generated.
* OpenUSD-25.11.tar.gz extracts as OpenUSD-25.11.
  contain-python-copysign-macro.patch keeps the Windows CPython macro from
  rewriting C++ calls to std::copysign.
  sort-hydra-repr-selectors.patch orders the Hydra render index's representation
  selectors before the dirty list merges them. An unordered list can trigger
  MSVC's Debug STL assertion during viewport startup.

bzip2 / freetype
---------------------------------

  header space for post-install path updates. Stop if install_name.sh fails.
* Build FreeType after Bzip2, PNG, and zlib-ng; use the selected prefix's headers,

llvm 20.1.3
---------------------------------
* LLVM 20.1.3 uses std::string for ClIgnorelist; the LLVM 16 sancov patch is

* rdf-comparators.patch backports LLVM commit 4bed796a5fea (PR #160804).

  pxr.Tf alone segfaults during Python shutdown. This also reproduces outside
  the new SDK shell. Loading Usd and creating an in-memory stage exits cleanly.

Shared lean LLVM recipe
-----------------------
* Keep llvm-project-20.1.3.src.tar.xz and rdf-comparators.patch unchanged.
  Share the existing Windows LLVM/Clang options and configure/build/install
  helper between platforms. Disable tests, examples, benchmarks, LLVM tools,
  and optional zlib, zstd, and libxml2 dependencies. Limit compilation to four
  jobs and linking to one job.
* Windows retains its X86 backend, static LLVM components, and libclang DLL.
  Mac retains shared libraries and the Clang driver for PySide header discovery,
  builds only the native AArch64 or X86 backend, and disables unrelated Clang
  tool directories. Track the installed driver aliases, TableGen tools, shared
  libraries, compiler resources, headers, and LLVM/Clang CMake exports.
* Isolate Git patch application from the enclosing checkout using the extracted
  source's parent as GIT_CEILING_DIRECTORIES. Otherwise Git can silently skip
  archive-relative paths under an ignored build directory. Allow the existing
  LLVM backport's zero-context hunks and report applied files explicitly.
