In progress improvements
---------------------------------
* Break for Qt builds in build.sh if not successful
* Fix verbose consistency across projects
* Zlib pkg-config path is in root instead of lib
* Qt and PySide use Ninja; switching other dependency recipes remains experimental

In progress notes
---------------------------------
* ninja moved to build_dir/ninja to not conflict in projects with clang, pyside.
  Clang system includes will not be generated properly when 3rdparty 
  clang binaries are exposed prior to system clang.

Fixes:

bzip2 / freetype
---------------------------------
* Build Bzip2 dylibs with the selected prefix as their install name and reserve
  header space for post-install path updates. Stop if install_name.sh fails.
* Build FreeType after Bzip2, PNG, and zlib-ng; use the selected prefix's headers,
  libraries, and pkg-config metadata to avoid mixing Debug and Release libraries.

llvm 20.1.3
---------------------------------
* LLVM 20.1.3 uses std::string for ClIgnorelist; the LLVM 16 sancov patch is
  no longer needed.
* rdf-comparators.patch backports LLVM commit 4bed796a5fea (PR #160804).
  Replace stateful std::less/std::equal_to specializations with RDF comparators
  for current libc++ compatibility; adjusted upstream unit-test context for 20.1.3.

opentimelineio / rapidjson / minizip-ng
---------------------------------
* minizip-ng enables Bzip2 compression using the existing bzip2 project,
  alongside Store/Deflate through zlib-ng. No additional packages are required.
* Fexternal dependencies, CMake 3.27 compatibility, safe std::any
  conversion, macOS library paths, and installed C++ consumer checks.


qt 6.10.1
---------------------------------
* src/scripts/patch_qt.py adds <arm_acle.h> to qyieldcpu.h on ARM for
  AppleClang 21's __yield declaration. build.sh applies this idempotently.
* Multimedia is enabled; reused Qt build trees are reconfigured.
* Disable dup3 for compatibility with macOS deployment targets before 27.
* Use Qt's default multi-config build/install targets so Release tools such as
  moc are installed alongside Debug frameworks.
* Stop on Qt build/install failures and require PySide's Qt package from the
  selected prefix to avoid mixing Debug and Release Qt/LLVM libraries.
